## What V9 contains

- Native C MoonViT vision tower and projector.
- Official-compatible image preprocessing and image-chat token expansion.
- BF16 media-embedding boundary into the text decoder.
- 27-layer native C text decoder with MLA and sparse MoE.
- Layer-major batched multimodal prompt prefill.
- Compressed incremental MLA KV state.
- SSD-resident streamed experts with a bounded expert cache.
- Linux `O_DIRECT` and Windows `FILE_FLAG_NO_BUFFERING` direct-I/O paths.
- One-command local model packer: `tools/pack_full_model.py`.
- One-command image chat frontend: `tools/kvl_vl_chat.py`.

## Semantic caveat

The released model itself is inconsistent across language/prompt formulations on the Vietnamese manga fixture. A stricter Vietnamese prompt asking only for visible eye/eyebrow/mouth features still produced a description inconsistent with the English control. Because the C generated prefix was verified 24/24 against the released BF16 greedy decoder, this behavior is recorded as a **model-level semantic limitation**, not hidden or reclassified as a runtime failure.

Accordingly, the final V9 acceptance gates runtime correctness and image conditioning, while semantic answer quality remains a property of the upstream model.

## Low-RAM invariants retained

The final acceptance retains the intended architecture:

- weights remain SSD/NVMe resident instead of being loaded as one full RAM image;
- expert cache is hard-bounded (512 MiB in the final CI gate);
- MLA uses compressed incremental state;
- vision and text phases are separate so vision working memory is released before text decoding;
- direct-I/O remains enabled for both trunk and expert stores;
- no model weights are stored in git.

## Quick local path

Build:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Pack a complete official seven-shard checkpoint:

```bash
python tools/pack_full_model.py /path/to/Kimi-VL-A3B-Instruct /path/to/kimi-vl-v9-packed
```

Run image chat:

```bash
python tools/kvl_vl_chat.py /path/to/kimi-vl-v9-packed image.jpg "Describe this image." \
  --cache-mib 512 --ram-mib 4096 --max-new 32 --temperature 0
```

On Windows, CMake's Release binaries are detected automatically by the Python frontend when built under `build/Release/`.
